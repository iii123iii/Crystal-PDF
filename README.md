## 🚀 Quick Start

### Prerequisites
- Node.js >= 18 (or Python >= 3.10)
- Git

### Installation
```bash
git clone https://github.com/iii123iii/Crystal-PDF.git
cd Crystal-PDF
```

### Development
```bash
npm install  # or pip install -r requirements.txt
npm test
npm run dev
```
