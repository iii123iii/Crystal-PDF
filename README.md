# Crystal-PDF

Full-stack PDF manipulation platform. Stateless Spring Boot REST API + React SPA.

## Documentation

### Local Development
1. **Backend**: Java 17+, Maven/Gradle
2. **Frontend**: Node.js 20+, npm
3. **Start**: `docker-compose up`
4. **Tests**: `mvn test` (backend), `npm test` (frontend)

### CI Pipeline
- GitHub Actions workflow at `.github/workflows/boost-quality.yml`
